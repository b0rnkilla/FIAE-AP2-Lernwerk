# AP2 Lernwerk 1.0.0-beta.2

### Verbessert

- `AP2-Lernwerk.exe` trägt jetzt das blaue a²-Symbol des Lernwerks. Es ist auch im Windows-Explorer sichtbar.
- Die README erklärt den SmartScreen-Hinweis beim ersten Start der unsignierten GitHub-Ausgabe.

### Start und Update

Die bisherige App beenden, das vollständige Windows-ZIP in einen neuen Ordner entpacken und `AP2-Lernwerk.exe` starten. Lernstand und Einstellungen bleiben erhalten.
